# QA Pilot Desktop — Системный бэклог задач (BACKLOG.md)

В данном документе зафиксирован полный скоуп архитектурных и функциональных модулей системы QA Pilot Desktop, сгруппированных по 4 ключевым доменам.

---

## 1. `[FRONTEND]` (Пользовательский интерфейс и визуализация)

- [x] Начальный макет интерфейса в темной палитре (VS Code / Discord dark theme)
- [x] Компонент рендеринга дерева файлов проекта в боковой панели (`Sidebar.tsx`)
- [x] Терминал логов в реальном времени с цветовой индикацией важности (ошибка, предупреждение, инфо, успех) (`ConsoleLogs.tsx`)
- [x] Виджеты визуального дашборда для комплексной оценки качества проекта (Overall Score, Health Radar)
- [x] Модальное окно настроек (ввод и валидация Gemini API Key, параметры запусков Playwright, headless/headed режим)

---

## 2. `[BACKEND & IPC]` (Главный процесс и IPC мост)

- [x] Базовый каркас IPC-каналов и изоляции контекста (`app:ping`, `app:get-system-info`)
- [x] Обработчик нативного системного диалога выбора директории (`dialog.showOpenDialog`)
- [x] Рекурсивный сканер файловой структуры с фильтром исключений (`node_modules`, `.git`, `.next`, `dist`, `build`, `out`, `.vscode`, `coverage`)
- [x] Селективный парсер исходного кода (чтение `package.json`, входных файлов и конфигов для формирования контекста Gemini AI)
- [ ] Механизм потоковой передачи логов и событий воркеров в реальном времени (Main -> Renderer IPC streaming)

---

## 3. `[CORE ENGINE]` (Ядро тестирования и краулер)

- [ ] Интеграция и конфигурация Playwright Test Runner (активация headed mode по умолчанию, выбор браузеров Chromium/Firefox/WebKit)
- [ ] Модуль автоматизированного обхода веб-приложения и эмуляции пользовательских действий (автокраулер страниц и форм)
- [ ] Логгер перехвата сетевых сбоев HTTP 500+ и крашей браузерной консоли (JS console errors, uncaught exceptions)

---

## 4. `[AI INTEGRATION]` (Интеллектуальный анализ Gemini)

- [ ] Интеграция официального Google Gemini SDK в главном процессе Electron
- [ ] Анализатор архитектуры и структуры файлов для выявления уязвимых и нетестированных областей проекта
- [ ] Модуль разбора стек-трейсов ошибок и генерации рекомендаций по их устранению
- [ ] Модуль расчета совокупного скоринга качества (Overall QA Score) и формирования итогового отчета по проекту
